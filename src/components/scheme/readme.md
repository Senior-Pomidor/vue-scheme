# SchemeMain - схема зала с местами

## Задача
- Отображение схемы
- Общение с JQuery в месте встраивания

## API

#### Props
1. seats (Objects Array) - массив с местами на cхеме
2. seatSelectionKey - параметр, по которому будут выделяться места

#### Events (emitters)
1. changed-seats-state (fn => ref({})) - При изменении состояния мест (выделение, развыделение, отмена) возвращает новое состояние мест
